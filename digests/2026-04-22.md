### 💼 Xbox Game Pass Ultimate月费降至22.99美元

根据Xbox官方公告，自今日起，Xbox Game Pass Ultimate的月费从29.99美元下调至22.99美元，降幅约23%。同时，PC Game Pass的月费也从16.49美元降至13.99美元。官方还宣布，从今年开始，未来的《使命召唤》系列新作将不再于首发日加入Game Pass，而是会在次年假日季（约一年后）入库，现有库中的《使命召唤》游戏则不受影响。

此次降价是Xbox Game Pass自2023年7月提价后的首次反向调整，直接回应了用户对订阅服务性价比的反馈。将《使命召唤》新作的入库时间推迟一年，是微软在收购动视暴雪后，平衡巨额收购成本与订阅服务内容吸引力的一次关键策略调整。此举旨在通过降低入门门槛吸引新用户，同时优化内容成本结构，以应对日益激烈的订阅市场竞争。

长期来看，这标志着Xbox订阅服务策略从“不计成本获取内容”转向更可持续的“精细化运营”。通过区分顶级3A大作与常规首发游戏的入库策略，微软试图在用户增长、内容支出和平台生态健康之间找到新的平衡点。这一模式可能成为未来主流游戏订阅服务的参考，即通过分级内容释放节奏来管理成本与用户预期。

### 💼 XGP降价至22.99美元，COD新作不再首发

微软官方宣布调整Xbox Game Pass订阅价格与服务内容。自即日起，顶级订阅服务Game Pass Ultimate月费从29.99美元降至22.99美元，PC版Game Pass从16.49美元降至13.99美元。同时，未来《使命召唤》系列新作将不再于发售首日加入XGP，而是延迟约一年，在次年假日季上线。此次调整由新任Xbox CEO Asha Sharma主导，她此前曾表示XGP“定价过高”，需在价值与灵活性间寻求平衡。

此次降价是微软对2024年涨价引发用户流失的直接回应，旨在挽回核心玩家。将《使命召唤》新作移出首发阵容，则显著降低了XGP的内容成本压力，标志着微软从“不计成本获取内容”转向更可持续的订阅模式。此举与任天堂、索尼近期调整数字版定价策略的趋势一致，反映出主机厂商在硬件成本上升、玩家支出趋紧的市场环境下，正重新评估订阅服务的价值定位。

长期来看，这可能是XGP服务模式重大转型的开端。近期传闻微软正考虑推出广告支持的低价订阅档位，或与Netflix等服务捆绑销售。此次降价与内容策略收缩，为未来更灵活、分层化的订阅方案铺平了道路。然而，随着下一代Xbox主机“Project Helix”的临近，硬件价格的潜在上涨可能再次考验玩家的忠诚度。

### 💼 《地狱潜者2》机甲专家通行证4月28日上线

根据Arrowhead游戏工作室社区经理Mitchell Ayre在PlayStation官方博客的公告，《地狱潜者2》最新战斗通行证“机甲专家”将于4月28日正式推出。该通行证包含两款新机甲EXO-51 Lumberer与EXO-55 Breakthrough、两款新武器SMG-203 Gallant冲锋枪与P-33导弹手枪，以及两套附带“氧气发生器”增益效果的新护甲。解锁该通行证需要玩家拥有游戏本体、超级点数并满足一定的游戏进度要求。
