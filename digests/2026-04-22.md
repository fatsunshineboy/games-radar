### 💼 XGP降价至22.99美元，新《使命召唤》首发不入库

微软于4月21日通过官方渠道Xbox Wire宣布，自即日起下调Xbox Game Pass Ultimate和PC Game Pass的订阅价格。其中，XGP Ultimate月费从29.99美元降至22.99美元，PC Game Pass月费从16.49美元降至13.99美元。同时，官方确认从今年起，未来的《使命召唤》系列新作将不再于首发日加入XGP，而是会在次年假日季入库，现有游戏库中的《使命召唤》作品不受影响。

此次降价是微软新任Xbox负责人Asha Sharma上任后的首个重大价格调整，直接回应了其内部备忘录中提到的“服务对玩家而言变得过于昂贵”的问题。此举旨在提升订阅服务的性价比，以应对市场竞争并稳定用户增长。将《使命召唤》新作首发排除在XGP之外，则可能是一种平衡高额收购成本与订阅服务长期可持续性的策略，标志着微软在整合动视暴雪内容后，对“首发入库”模式进行重新评估与调整。

### 💼 XGP降价至22.99美元，COD新作不再首发入库

微软正式下调Xbox Game Pass订阅价格，最高档Game Pass Ultimate月费从29.99美元降至22.99美元，PC版从16.49美元降至13.99美元。同时，未来《使命召唤》系列新作将不再于发售首日加入XGP，而是延迟约一年，在次年假日季入库。此次调整由新任Xbox CEO Asha Sharma主导，她在内部备忘录中曾指出当前订阅服务“定价过高”。

此次降价是微软在去年涨价引发用户流失后的策略回调，旨在平衡订阅服务的价值与价格。将《使命召唤》这类顶级IP移出“首发入库”阵容，显著降低了XGP的内容成本压力，标志着微软正从“不计成本扩张用户”转向更可持续的商业模式。此举也反映了整个游戏行业在硬件成本上升、玩家消费趋于谨慎的大环境下，对订阅制价值的重新评估。

可以预见，XGP未来可能进一步分层，例如推出含广告的廉价档位或与Netflix等流媒体捆绑。此次调整是微软应对市场变化、优化利润结构的第一步，也为即将公布的新主机“Project Helix”可能的高定价预留了空间。订阅制游戏服务正从“内容军备竞赛”进入精细化运营的新阶段。

### 💼 XGP调整政策：COD首发不入库，月费降价

### 💼 《地狱潜者2》新战斗通行证“机甲专家”4月28日上线

根据PlayStation官方博客4月21日发布的消息，Arrowhead Game Studios开发的《地狱潜者2》将于4月28日推出名为“机甲专家”的全新战斗通行证。该通行证将包含两款新机甲“EXO-51 Lumberer”与“EXO-55 Breakthrough”，以及“MGX-42 Bullet Storm”一次性机枪、“SMG-203 Gallant”冲锋枪等新武器，并附带两款新护甲、披风和表情动作。解锁新内容需要玩家拥有游戏本体、超级货币并完成一定的游戏进度。

此次更新是《地狱潜者2》自2月发售以来持续内容运营策略的关键一步。通过定期推出包含新武器、机甲和外观的付费战斗通行证，Arrowhead在维持游戏热度和玩家活跃度的同时，也构建了稳定的长期收入模型。新机甲“EXO-51 Lumberer”和“EXO-55 Breakthrough”分别强化了反装甲与阵地防御能力，有望改变玩家在高难度任务中的战术组合，为合作玩法注入新变数。

从行业角度看，《地狱潜者2》凭借出色的首发表现和持续的社区运营，已成为服务型游戏的一个成功范本。此次更新进一步印证了其“游戏即服务”的核心理念，即通过高质量、有主题的周期性内容来延长游戏生命周期。在当前服务型游戏竞争激烈的市场环境下，Arrowhead能否保持内容更新的节奏与创意，将是其能否持续留住玩家、避免热度下滑的关键考验。

### 🎮 《阿尔比恩Online》今日登陆Xbox主机

根据Xbox官方新闻稿，由德国工作室Sandbox Interactive开发的沙盒MMORPG《阿尔比恩Online》于今日（2026年4月21日）正式登陆Xbox Series X|S平台，以免费游戏形式推出。该版本支持与PC、移动端的完全跨平台游玩，并针对手柄操作进行了UI重制和战斗优化。Xbox Game Pass订阅者还可通过账户联动，领取包含“精英绿骑士”外观、3天高级会员及声望书的专属奖励包。

此次登陆Xbox主机是《阿尔比恩Online》自2017年上线以来，继去年登陆PC版Xbox应用后，在平台扩展上的又一关键步骤。对于这款以玩家驱动经济和大型公会战为核心、已运营近十年的MMO而言，接入Xbox生态意味着触达更广泛的主机玩家群体，有望为其稳定的玩家社区注入新活力。跨平台无缝衔接的特性，也降低了主机玩家的尝试门槛，强化了其作为“服务型游戏”的长期运营基础。

从行业趋势看，成熟PC端MMO向主机平台的移植正成为常态，如《最终幻想14》、《命运方舟》等。此次《阿尔比恩Online》的移植，不仅展示了跨平台技术方案的成熟，也反映了微软在丰富Xbox平台MMO产品线、吸引核心网游用户上的策略。其免费模式与Game Pass福利的结合，将成为微软服务订阅体系吸引和留存重度玩家的又一案例。
